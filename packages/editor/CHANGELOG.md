- [#22](https://github.com/flovan/plakboek/pull/22) [`ea4404b`](https://github.com/flovan/plakboek/commit/ea4404beec26a7f0de0e0818a11f469e601b120a) Thanks [@flovan](https://github.com/flovan)! - Editing a block component under `pnpm dev` now swaps just that block instead of reloading the page. - [#22](https://github.com/flovan/plakboek/pull/22) [`3e675f7`](https://github.com/flovan/plakboek/commit/3e675f75b063a81b7be93bb7b62fe5817b375fcf) Thanks [@flovan](https://github.com/flovan)! - Add the edit and preview routes to the editor API. `POST /cms/api/pages/:id/edit` applies a batch of up to 50 insert, update, move, delete and duplicate operations as one write and answers the new page version, the page tree and the rendered fragments the frame needs to follow the change: only the updated blocks for a property edit, the touched top level sections for a structural one. `POST /cms/api/pages/:id/preview` renders one block with candidate values using the checks a write applies, without writing, locking or bumping the version, and reports invalid values by key and code only.

- [#22](https://github.com/flovan/plakboek/pull/22) [`ad630f2`](https://github.com/flovan/plakboek/commit/ad630f2235b056b3b73f33bef268e49ef67a7bca) Thanks [@flovan](https://github.com/flovan)! - Add the editor's JSON API on the server: `createEditorApi` answers `/cms/api` for core to mount. `POST /cms/api/open` takes a page's visitor path and returns everything the editor starts with (the page id and version, the block catalogue built on the server so hidden properties never leave it, the column-shaped tree, the lock, the column presets and the limits) and takes the page's edit lock when it is free. The frame now marks column cells as columns.
