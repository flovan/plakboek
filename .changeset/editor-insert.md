Add blocks and sections from the page. Hovering the gap between siblings of the current scope level shows an insert point, and its `+` button opens a searchable picker of only the types legal there, grouped by category. An empty column shows an "Add block" prompt and a page with no sections shows an "Add a section" card. The toolbar gains Add after, the `+` key does the same from the page region, and the sidebar holds a Blocks palette that adds a type right after the selection at the nearest level where it is legal. A new item starts with its default values and starter children, is selected once saved and is announced as added, and a block with a required value still missing carries a "Needs input" marker.
