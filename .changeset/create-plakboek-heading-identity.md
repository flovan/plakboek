The starter heading now spreads `{...edit}` on its h1, h2 or h3. On a new site the page editor can outline the heading, select it and reach it by double-clicking through its section and column; before, a double-click stopped at the column. The README now names the root spread and the field spread. A site created from an earlier starter gets the fix by adding `{...edit}` to the three heading elements in `blocks/heading.tsx`.
