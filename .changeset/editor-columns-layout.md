Add, remove and re-order a section's columns, and lay them out, by clicking. A selected section's Properties show a Columns group (one row per column with how many blocks it holds, move earlier, move later and remove, and Add column), a Layout group (preset tiles for the live column count and a four-way alignment choice) and then its Settings. Adding or removing a column, from the panel, the lines between columns, a column's Add after, or by copying, deleting or moving a column from the toolbar or keyboard, is one write together with the switch to the equal split, and one undo step. Removing a column that holds blocks asks first and says how many go with it. A block that supports it gets a Placement group with Fill column height, and a selected column points to its section's layout.
