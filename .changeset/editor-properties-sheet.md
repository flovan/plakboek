Properties now open in a focused panel that slides over the sidebar, with a Close button that slides it away again. This replaces the Blocks and Properties tabs: the sidebar shows the Blocks palette only, and the Properties panel opens when you ask for it with a double-click, Enter on a block, the toolbar's Properties button, or when an insert needs input. In the full-width layout the panel slides over the drawer the same way. While it is open it follows the selection, carries the page notice, the lock reminder and the save status so none of them is hidden, and Escape closes it before it closes the drawer.
