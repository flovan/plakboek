One click in Edit mode now selects the deepest item under the pointer: a block inside a column inside a section, the column on empty column space, the section on empty section space. Hover outlines the same item a click would select. Escape climbs one level at a time and the breadcrumb and Page structure select any ancestor. A double-click on the page no longer opens Properties; use the toolbar's Properties button, the Page structure or the needs-input marker.
