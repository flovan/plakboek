Edit a block's properties from the side panel. The panel region gains Blocks and Properties tabs, switched only by an explicit action: the tab, the toolbar's new Properties button, a double-click or Enter on a leaf, or adding a block that still needs a value (which also focuses its first empty required control). Properties shows a control for every property the block declares, with a native control for each field-type widget, and read-only notes for the rich text, media and entry pickers that arrive later. A property the installation hides is not shown, a fixed one is disabled, and a narrowed one offers only its allowed values. Changing a value re-renders the block in the frame with its real component (text after 150ms of quiet, pickers, switches, selects and sliders at once) without touching the panel's focus or caret, an invalid value is shown under its field and leaves the frame on the last valid render, and a required value that is empty shows "Needs input". Changes are saved after a pause or on blur, a burst of keystrokes in one field is a single undo step, and undoing it restores the block in the frame, the panel and storage.
