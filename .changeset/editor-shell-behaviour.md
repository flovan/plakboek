Gives the edit shell its behaviour. The shell opens framed and a Full width toggle switches to a 56px rail with the page flush; the choice is kept per browser and applied before first paint by a constant, hash-allowed inline script, so the framed layout never flashes. The rail carries the toggle, Exit edit mode, an avatar and Log out as icon buttons with CSS tooltips. A link to another page of the site, clicked in the frame, navigates the whole page in edit mode; a link to another site opens in a new tab with `noopener`; same-page links, downloads, named targets and modified clicks keep the browser's behaviour, and a click the site's own script handled is left alone. A frame navigated by a script or a form is followed by the whole page. Below 1024px the frame is replaced by a panel asking for a wider window, and a page whose edit render fails shows a panel with a Reload page button and no error detail. The shell's title follows the page's, and Log out clears the editor flag in the browser.
