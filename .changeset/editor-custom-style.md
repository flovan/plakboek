An editor can step outside the theme on purpose. When the theme declares colours, sizes or alignment, the text toolbar gets a Custom style button that opens a second row with Size, Color, Alignment and Reset style. Colour and size offer the theme's labelled entries first, stored as references that follow theme changes, and a free hex colour or pixel size when the theme allows custom values; Reset style (or Ctrl/Cmd+\) strips colour, size and alignment from the selection in one undoable step. While editing, text that differs from the theme is marked with a dashed line under it, only for the selected block, and never in what visitors receive.
