Edit a button block on the page and in Properties. A link property gets the same Link target section the link and button popovers use (search for a page or enter a web address, open in a new tab), and a link field that names its label and style properties opens the Button popover when it is clicked, so a standalone button and a button typed into a text are edited the same way.
